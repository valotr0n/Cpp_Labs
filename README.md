## Переменные, типы, операторы и условия

Переменная — именованное место для значения. В `int count = 0;` тип `int` означает целое число, `count` — имя, `0` — начальное значение. `double` хранит приближённые вещественные числа, например `-2.75`. `bool` хранит `true` или `false`. `char` в этих программах хранит один байт строки. `long long` — целочисленный тип, который в используемой Windows-сборке шире `int`.

**Объявить** переменную и **дать ей значение** — разные действия. После `int n;` локальное число ещё не инициализировано: читать его до успешного ввода нельзя. В `if (!(cin >> n) || n < 1)` это безопасно: если ввод не удался, вторая часть условия не выполняется.

У операторов разные роли:

- `=` присваивает значение: `maximum = count` записывает `count` в `maximum`.
- `==` сравнивает: `count == 0` спрашивает, равно ли значение нулю.
- `!=` означает «не равно». `<`, `>`, `<=`, `>=` сравнивают числа.
- `+=` прибавляет с сохранением: `sum += x` означает `sum = sum + x`.
- `++count` увеличивает счётчик на единицу. В отдельной строке здесь подходит и `count++`; различие проявляется, когда результат выражения используют дальше.
- `%` вычисляет остаток целочисленного деления. `-14 % 7 == 0`, поэтому проверка кратности работает и для отрицательных чисел.
- `!` меняет логическое значение на противоположное: `!found` означает «ещё не найдено».
- `&&` требует истинности обеих частей. `x < 0 && x % 7 == 0` выбирает отрицательные кратные 7.
- `||` требует хотя бы одной истинной части. `n < 1 || n > 100000` обнаруживает выход за допустимый диапазон.

`&&` и `||` выполняют **короткое замыкание**: правая часть вычисляется только при необходимости. Например, в `*p != '\0' && !isSeparator(*p)` проверка разделителя нужна только до конца строки.

`if (условие)` выполняет следующий оператор или блок `{ ... }`, если условие истинно. `else` выполняется при ложном условии. Если фигурных скобок нет, условию принадлежит **ровно один следующий оператор**, даже если отступы выглядят иначе.

`while` проверяет условие перед каждой итерацией. `while (true)` повторяется, пока не встретится `return`, `break` или исключение. `break` выходит только из ближайшего цикла. `return` завершает текущую функцию; в `main` он завершает программу.

```cpp
for (int i = 0; i < 3; ++i) {
    cout << i << ' ';
}
```

Сначала один раз создаётся `i = 0`. Потом проверяется `i < 3`. Если проверка успешна, выполняется тело, затем `++i`, затем новая проверка. Получится `0 1 2`. При `i == 3` тело уже не выполняется.

Фигурные скобки создают блок и область видимости. Переменную, объявленную внутри блока, по имени обычно видно только до его закрытия. `;` завершает оператор; после определения функции отдельная точка с запятой не нужна.

## Массивы, индексы и границы

Массив хранит несколько элементов одного типа подряд. `double x[20];` создаёт двадцать чисел. Индексы начинаются с нуля: первый элемент — `x[0]`, последний — `x[19]`. Номер для человека часто выводят как `индекс + 1`.

```text
индекс:      0    1    2    3
значение:   -8    3   -2    5
```

`arr[4]` для такого массива — выход за границы. Это не «ещё одна пустая ячейка», а недопустимое обращение. Встроенный массив и `vector` с оператором `[]` не обязаны сообщать об этой ошибке исключением.

Размер в записи `char text[1001]` относится к байтам, а не к количеству русских букв. А размер в `double x[20]` — к количеству элементов `double`, не байтов.

Чтобы найти максимум, удобно начать с первого элемента, затем сравнить с остальными. Начинать с нуля нельзя, если все числа могут быть отрицательными: у `[-8, -3, -6]` максимум `-3`, а нуля в массиве вообще нет.

## Указатели: адрес, звёздочка, nullptr, арифметика

Указатель — переменная, которая хранит **адрес объекта в памяти**. Обычная переменная хранит значение; указатель позволяет добраться до значения через его адрес.

```cpp
int value = 7;
int* p = &value;
cout << *p;  // 7
*p = 20;     // теперь value равно 20
```

Здесь важно различать три записи:

- `value` — само число.
- `&value` — адрес этого числа. Это применение оператора взятия адреса.
- `p` — указатель, которому присвоили этот адрес.
- `*p` — объект по адресу, хранящемуся в `p`. Получение доступа к нему называют **разыменованием**.

В объявлении `int* p` звёздочка говорит о типе переменной. В выражении `*p = 20` звёздочка обращается к объекту. А в `a * b` тот же символ означает умножение. Смысл определяется местом записи.

```text
p ──хранит адрес──> value
                    7
```

В этих программах имя массива часто преобразуется в указатель на его первый элемент. Поэтому `char* p = text;` позволяет перемещаться по `text`, а `double* maximum = arr;` изначально указывает на первое число. Сам массив и указатель — разные сущности: например, размер массива не хранится автоматически внутри указателя.

### Почему ++p переходит к следующему элементу

Указатель знает тип элемента. `++p` сдвигает его на один **элемент**, а не обязательно на один байт. Для `char*` это один байт, для `double*` — размер одного `double`.

```cpp
double arr[3] = {10, 20, 30};
double* p = arr;
++p;
cout << *p;  // 20
```

`p + 2` вычисляет другой адрес, но не меняет `p`. `++p` меняет сам указатель. `(*p)++` увеличивает значение в ячейке. В этих лабораторных используется `++p`, когда нужно идти по массиву.

`arr + n` указывает на позицию **сразу после массива**. Такой указатель можно получить и использовать как границу цикла, но разыменовывать нельзя. Поэтому условие `p < arr + n` проверяется до чтения `*p`.

Вычитание указателей внутри одного массива даёт расстояние **в элементах**. Если `maximum == arr + 3`, то `maximum - arr` равно `3`, а человеческий номер равен `4`.

### Что такое nullptr

`nullptr` — специальное значение «указатель ни на что не указывает». Оно удобно до выделения памяти или до нахождения результата. `if (!best)` проверяет, остался ли указатель пустым. Разыменовывать `nullptr` нельзя: наличие звёздочки в типе не гарантирует существование объекта.

### const char* и копия адреса

`const char* p` позволяет менять адрес в `p`, например делать `++p`, но запрещает менять символ через `*p`. Это не то же самое, что `char* const p`: во втором случае нельзя изменить сам указатель.

Когда указатель передают в функцию, **его адресное значение копируется**. Поэтому `++p` внутри функции не двигает указатель вызывающего кода. Но оба указателя могут указывать на одну и ту же память: изменение `*p` без `const` изменило бы общий объект. Это понадобится при чтении `isVowel` и `sameWord`.

## new, delete[] и время жизни памяти

`new int[10]` выделяет динамическую память под десять чисел и возвращает указатель на первый элемент. Здесь начальные значения этих чисел не задаются; код заполняет их до чтения. `new double[n]` позволяет выбрать размер после ввода пользователя.

```cpp
int* numbers = new int[10];
// Работа с десятью элементами.
delete[] numbers;
```

`delete[]` освобождает массив, созданный через `new[]`. Квадратные скобки важны: для одиночного `new int` используется `delete`, для `new int[10]` — `delete[]`.

После освобождения `numbers` сам по себе не превращается в `nullptr`. Его прежнее адресное значение больше нельзя использовать для доступа к освобождённым элементам. Если работу с переменной продолжают, её часто обнуляют. В наших программах после успешного освобождения сразу идёт `return`.

Память освобождается и в `catch`, потому что ошибка может произойти уже после `new[]`. Если память выделить и забыть освободить, получится утечка. `delete[] nullptr` безопасен: это позволяет выполнять очистку, даже если выделение памяти не состоялось.

Локальный `char text[1001]` живёт до выхода из своего блока. Указатели на слова внутри него действительны, пока жив этот массив. Его не нужно освобождать через `delete[]`: он создан без `new[]`.

`vector` управляет памятью самостоятельно. При обычном выходе из блока, `return` и раскрутке стека из-за исключения вызывается его деструктор и освобождает принадлежащую ему память. Такой подход называется **RAII**: ресурс привязан ко времени жизни объекта.

<a id="references"></a>
## Ссылки, const и разные значения символа &

Ссылка — другое имя уже существующего объекта.

```cpp
int x = 3;
int& alias = x;
alias = 9;  // изменится x
```

В `for (int& value : numbers)` переменная `value` ссылается на очередной элемент вектора. Поэтому `value = ...` заполняет сам вектор. Если написать `for (int value : numbers)`, в `value` будет отдельная копия: изменение копии не изменит элементы.

`const string& word` — ссылка на строку, которую нельзя менять через эту ссылку. Она нужна, чтобы передать строку без копирования всего текста и одновременно защитить его от изменения в функции.

Записи с `&` читаются по контексту: `&x` в выражении получает адрес, `int& x` в объявлении создаёт ссылку, а `&&` в условии — логическое «и». Это три разные роли символов.

`catch (const exception& e)` тоже использует константную ссылку: обработчик получает доступ к объекту ошибки без ненужной копии и сохраняет возможность вызвать его виртуальный `what()` для конкретного типа ошибки.

## vector и циклы по коллекции

`vector<T>` — контейнер стандартной библиотеки, динамический массив элементов типа `T`.

```cpp
vector<int> numbers(10); // десять int, изначально нули
vector<string> words;    // пока ни одной строки
words.push_back("hello");
```

Не путай `vector<int> numbers(10)` и `vector<int> numbers{10}`: в первом случае десять нулей, во втором — один элемент со значением `10`.

`arr[i]` даёт доступ к элементу по индексу. `words.size()` возвращает количество элементов, `words.back()` — последний элемент. Вызывать `back()` на пустом векторе нельзя; в программе перед этим проверяется минимальное число слов.

`push_back(word)` добавляет копию строки в конец. Вектор при необходимости увеличивает своё хранилище. Указатели и ссылки на его элементы при перевыделении памяти могут стать недействительными; в наших программах такие адреса между добавлениями не сохраняются.

У циклов по коллекции три важных варианта:

```cpp
for (double value : arr)       // копия, удобно для вывода
    cout << value;
for (double& value : arr)      // ссылка, можно менять элемент
    cin >> value;
for (const string& word : words) // без копии, без изменения
    cout << word;
```

Такой `for` называют range-based for — цикл по элементам диапазона. Если нужен индекс элемента, можно использовать обычный `for (int i = 0; i < n; ++i)`.

## C-строки, char, нулевой символ и UTF-8

C-строка — последовательность байтов `char`, завершающаяся нулевым байтом `\0`. Это не печатная цифра `'0'`, а специальный признак конца.

```text
слово "cat":
индекс:     0    1    2     3
байт:      'c'  'a'  't'  '\0'
```

Для трёх букв нужны четыре ячейки. Поэтому `char text[1001]` с `cin.getline(text, 1001)` позволяет сохранить до 1000 байт текста и завершающий ноль. Перевод строки при вводе считывается как разделитель и в массив не записывается.

`cout << p`, где `p` имеет тип `char*`, выводит байты от `p` до ближайшего `\0`. Поэтому изменение пробела на `\0` отделяет слово **внутри исходного массива**:

```text
до:     c a t _ d o g \0
после:  c a t \0 d o g \0
        ↑        ↑
      words[0] words[1]
```

`char* words[30]` — массив из тридцати указателей, а не место для тридцати отдельных копий слов. Сами буквы остаются в `text`. `words[i]` указывает на начало нужного слова. Копия указателя копирует адрес, а не содержимое строки.

### Почему русская буква может занимать два char

UTF-8 кодирует символы переменным числом байтов. Обычная латинская буква занимает один байт, русские буквы из наших списков — два. Поэтому `"а"` — это два байта плюс завершающий ноль, а `string("кот").size()` при UTF-8 равно `6`, а не `3`.

В `isVowel` каждая гласная хранится как короткая C-строка. Код сравнивает **все её байты**, а не пытается поместить русскую букву в один `char`. Внешний указатель идёт по одному байту. При старте на первом байте гласной проверка срабатывает, при старте на втором — уже нет; для корректного UTF-8 перечисленные гласные не считаются дважды.

Список гласных явно включает `y` и `Y`. Именно так устроен текущий алгоритм, независимо от того, как конкретное английское слово произносится.

Список разделителей также задан явно: пробел, табуляция, `\r`, точка, запятая, `;`, `:`, `!`, `?`, круглые скобки, обычная двойная кавычка и дефис. Например, длинное тире `—` и кавычки `«»` автоматически разделителями не становятся. Программа использует именно заданный набор.

`SetConsoleCP(CP_UTF8)` и `SetConsoleOutputCP(CP_UTF8)` задают кодовые страницы ввода и вывода консоли Windows. Они не превращают `char` в целую Unicode-букву и не меняют правила индексации `string`. Исходники предполагаются сохранёнными в UTF-8; работа вывода также зависит от терминала и шрифта.

<a id="strings"></a>
## string, find, substr и npos

`string` управляет строковым хранилищем сам. Можно присваивать строки, сравнивать их содержимое через `==` и `!=`, получать длину и искать фрагменты. Ручное добавление `\0` для отделения слов здесь не нужно: `substr` создаёт отдельную строку.

Основные методы из лабораторной:

- `text.size()` — длина в элементах `char`, то есть байтах этих UTF-8 строк.
- `text.empty()` — проверка на нулевую длину.
- `text.find(vowel)` — позиция первого совпадения **целой подстроки**.
- `text.find(vowel, start)` — поиск, начиная с позиции `start`.
- `text.find_first_of(separators, start)` — первая позиция любого байта из набора разделителей.
- `text.find_first_not_of(separators, start)` — первая позиция байта, не входящего в этот набор.
- `text.substr(start, length)` — копия участка, начиная со `start`, длиной не более `length`.

```text
текст:    _ c a t _ _ d o g
индекс:   0 1 2 3 4 5 6 7 8
start = 1
end   = 4
end - start = 3 → "cat"
```

`string::npos` — специальное значение «позиция не найдена». Оно имеет беззнаковый тип, не является обычным индексом и обычно представлено максимальным значением строкового типа размера. `size_t` — беззнаковый целочисленный тип, подходящий для размеров и позиций на этой платформе.

В текущем коде встречается `text.substr(start, end - start)` даже когда `end == string::npos`. В этом случае беззнаковое вычитание даёт очень большое количество, а `substr` ограничивает его оставшейся длиной строки. Получается последнее слово до конца. Это рабочая особенность именно этого выражения, но нельзя считать `npos` обычной позицией и обращаться к `text[npos]`.

Поиск гласных идёт с `pos + vowel.size()`, чтобы не находить то же совпадение снова. Для русской гласной это переход на два байта — сразу за найденную букву.

`best = word` копирует содержимое слова. В C-версии `best = start` сохраняет только адрес в исходном массиве. При одинаковом числе гласных обе версии оставляют **первое** подходящее слово: проверка использует `>`, а не `>=`.

<a id="streams"></a>
## Ввод, вывод и состояния cin

`cout << value` отправляет значение в стандартный вывод. Несколько `<<` позволяют собрать сообщение из текста и чисел. `' '` — символ пробела, `'\n'` — один символ новой строки, а `"\nСумма: "` — целая строка с переводом строки в начале.

`cin >> n` пропускает начальные пробельные символы и пытается прочитать значение подходящего типа. Выражение возвращает сам поток; в логическом условии поток сообщает об успешности операции. Поэтому `!(cin >> n)` означает «прочитать n не удалось».

`getline(cin, text)` читает строку целиком с пробелами в `string`. `cin.getline(text, 1001)` читает в C-массив с ограничением буфера. Это похожие задачи, но разные формы вызова.

После `cin >> answer` перевод строки обычно остаётся во входном потоке. Если сразу вызвать `getline`, можно получить пустую строку. Поэтому в обработчиках выполняется `cin.ignore(..., '\n')`: остаток текущей строки удаляется вместе с переводом строки.

Поток хранит флаги состояния:

- `cin.fail()` — предыдущая операция ввода не смогла выполнить задачу, например вместо числа пришло слово; для слишком длинной C-строки также устанавливается состояние ошибки.
- `cin.eof()` — была обнаружена граница входных данных. В обычной интерактивной работе это не то же самое, что просто нажать Enter.
- `cin.clear()` — очищает флаги ошибки. **Не удаляет плохой текст** из входного потока.
- `cin.ignore(numeric_limits<streamsize>::max(), '\n')` — пропускает остаток строки. `streamsize` — тип количества символов потока; максимальное значение здесь используется как практически неограниченный предел пропуска до `\n`.

В числовых версиях `clear()` и `ignore()` вызываются безусловно внутри `catch`. В строковых версиях очистка перед вопросом о повторе нужна только при `cin.fail()`: если ошибка была логической и строка уже прочитана, лишний `ignore()` мог бы ждать и поглотить следующий ввод.

**Ограничение текущих программ:** `cin >> int` не проверяет, что вся введённая строка является целым числом. Из `3.5` он может прочитать `3`, оставив `.5`. Проверки диапазона и флагов полезны, но это не строгий разбор всей строки. Аналогично ответ на вопрос о повторе предполагается корректным целым числом.

<a id="exceptions"></a>
## Исключения и повтор после ошибки

Исключение позволяет прервать обычный ход вычислений и перейти к обработчику ошибки.

```cpp
try {
    // Обычные действия.
    throw runtime_error("Неверный размер.");
    // Сюда после throw выполнение уже не дойдёт.
} catch (const exception& e) {
    cout << e.what();
}
```

`runtime_error` — стандартный класс ошибки с текстовым сообщением, подключается через `<stdexcept>`. Он наследуется от `exception`, поэтому соответствующий `catch` его перехватывает. `e.what()` возвращает описание ошибки.

При переходе к обработчику локальные объекты, покидающие область видимости, уничтожаются. Поэтому вектор освобождает своё хранилище автоматически. У обычного указателя такого владения нет: для динамического массива нужен явный `delete[]`.

В наших программах второй лабораторной внешний `while (true)` позволяет повторить **всю попытку**, а не продолжить с места ошибки. Ввод `1` оставляет выполнение внутри цикла, другой ответ приводит к `return 1`. Успешный результат заканчивается `return 0`.

В третьей лабораторной ошибки обрабатываются обычными проверками и выходом через `return 1`, без `try/catch`. Сам по себе `try/catch` не исправляет неверный индекс, разыменование пустого указателя или любые другие ошибки памяти: такие действия не обязаны превращаться в перехватываемые исключения C++.

<a id="functions"></a>
## Функции и передача массива

Функция — именованный участок кода для отдельной задачи. В `double findMax(const double arr[], int size)` слева указан тип результата `double`, затем имя, затем параметры.

```cpp
double square(double value) {
    return value * value;
}
double result = square(3); // result равно 9
```

`value` — параметр в объявлении функции, `3` — аргумент конкретного вызова. При передаче по значению функция получает копию. `return` передаёт результат вызывающему коду и заканчивает работу функции.

В `findMax(x, 20)` функция получает доступ к элементам `x` и отдельно число `20`. Параметр `const double arr[]` в такой записи фактически является `const double*`: массив целиком не копируется, длина автоматически не передаётся. `const` запрещает менять элементы через этот параметр.

Размер, написанный в параметре как `arr[20]`, сам по себе тоже не обеспечил бы контроль длины обычного указательного параметра. Обязанность передать настоящий размер лежит на вызывающем коде. Наши вызовы используют фиксированные массивы и согласованные размеры.

Каждый вызов имеет собственные локальные переменные. `maximum` внутри `findMax(x, 20)` и `maximum` внутри последующего `findMax(y, 15)` — отдельные значения разных вызовов.

`main` — точка входа программы. Её результат получает среда запуска. Ноль традиционно означает успешное завершение, ненулевой код — ошибку. `using namespace std;` позволяет писать `cout`, `vector`, `string` вместо `std::cout`, `std::vector`, `std::string`.

`#include` обрабатывается до компиляции основного кода: подключает объявления из заголовка. `<iostream>` нужен для потоков, `<cmath>` — для математики, `<vector>` — для вектора, `<string>` — для строки. `<windows.h>` нужен для функций консоли Windows; из-за него эти программы в текущем виде рассчитаны на Windows.

<a id="recursion"></a>
## Рекурсия и стек вызовов

Рекурсия — вызов функцией самой себя. Каждый вызов должен либо сразу вернуть готовый ответ, либо приблизить задачу к такому ответу.

В `PowerN` базовый случай — `N == 0`: результат равен `1`. Положительный показатель уменьшается: чётный делится на два, нечётный уменьшается на один. Отрицательный переводится в положительный, после чего берётся обратная величина.

Когда вызов ждёт результата другого вызова, его параметры и промежуточное состояние сохраняются. Удобно представлять это как стек карточек: сначала кладём новую карточку сверху, потом снимаем её и возвращаем ответ предыдущей.

```text
PowerN(2, 5)
  ждёт 2 * PowerN(2, 4)
    ждёт квадрат PowerN(2, 2)
      ждёт квадрат PowerN(2, 1)
        ждёт 2 * PowerN(2, 0)
          возвращает 1
        возвращает 2
      возвращает 4
    возвращает 16
  возвращает 32
```

В строке `double half = PowerN(X, N / 2);` функция вычисляется **один раз**. Затем `half * half` использует уже готовое значение. Если вместо этого дважды написать `PowerN(X, N / 2)`, одинаковая работа будет повторяться.

Благодаря делению чётного показателя глубина вызовов растёт примерно как логарифм его абсолютной величины. У нечётного положительного показателя вычитание единицы делает его чётным, и следующий шаг снова делит пополам. Это гораздо меньше, чем N последовательных умножений при большом N.

В записи `N / 2` оба операнда целые, поэтому используется целочисленное деление. В этой ветке N положительно и чётно, остатка всё равно нет. А в `1 / PowerN(...)` второй операнд имеет тип `double`, поэтому результат деления вещественный: `1 / 8.0` даёт `0.125`.

У текущей функции параметр `long long`, но `main` передаёт только значения `int`. Это позволяет безопасно изменить знак самого маленького вводимого `int` после расширения типа. Если отдельно вызвать функцию с минимальным возможным `long long`, выражение `-N` уже не представимо этим типом; такой расширенный случай текущая функция не поддерживает.

<a id="random"></a>
## Случайные числа и преобразование типа

`rand()` выдаёт очередное псевдослучайное целое число. Последовательность зависит от начального состояния генератора. `srand(seed)` задаёт его; при одинаковом seed последовательность воспроизводится.

```cpp
srand(static_cast<unsigned int>(time(nullptr)));
```

`time(nullptr)` получает текущее календарное время в представлении библиотеки. Здесь `nullptr` означает, что функция не должна дополнительно записывать его по переданному адресу. `static_cast<unsigned int>` явно приводит результат к беззнаковому целому типу, который принимает `srand`. Это преобразование типа, а не отдельный генератор.

Инициализация стоит до цикла, чтобы не начинать последовательность заново на каждой попытке. Два запуска с одним и тем же начальным временем могут дать одинаковые числа.

`rand() % 101` даёт остатки от `0` до `100`, а вычитание `50` сдвигает диапазон до `-50..50` включительно. Деление с остатком может давать небольшую неравномерность распределения. Для учебного заполнения массива здесь достаточно, но это не криптографический генератор.

<a id="math"></a>
## Модуль, целая часть, экспонента и точность

`fabs(x)` вычисляет модуль вещественного числа: `fabs(-8.5) == 8.5`. Поэтому максимальный по модулю элемент у `[-8, 3, -2]` — `-8`, хотя обычный максимум — `3`.

`trunc(x)` отбрасывает дробную часть **к нулю**. `trunc(2.9) == 2`, `trunc(-2.9) == -2`. Это отличается от округления вниз, которое дало бы для `-2.9` число `-3`. Результат `trunc` остаётся вещественным значением, хотя дробной части уже нет.

`sqrt(x)` вычисляет квадратный корень, `exp(x)` — e в степени x, где e приблизительно равно `2.71828`. `exp(fabs(xMax))` означает e в степени модуля максимума, а не модуль экспоненты и не экспоненту максимального по модулю элемента.

`isfinite(x)` проверяет, что число не является бесконечностью или NaN — специальным значением «не число». Но конечное значение всё равно может быть округлено: `double` не хранит все вещественные числа точно.

При слишком большом результате возможно переполнение, при слишком маленьком — потеря значащих цифр или округление до нуля. `isfinite` не обнаруживает все такие потери. Например, математически ненулевая отрицательная степень может округлиться до нуля, и этот ноль останется конечным числом.

В формуле третьей лабы произведение `xMax * yMax` и экспоненты вычисляются до итогового деления. Поэтому на крайних входных значениях промежуточное переполнение или потеря точности возможны даже тогда, когда иначе организованное вычисление дало бы более точный результат. Текущий код — прямой учебный перевод формулы.

В выводе степень обозначена текстом `^`. В самом C++ оператор `^` для целых означает побитовое исключающее ИЛИ, а не возведение в степень. Наш код вычисляет степень рекурсивной функцией и лишь печатает этот знак.

**Одинаковый алгоритм:** замена способа хранения не превращает эту перестановку в сортировку и не добавляет сохранение порядка неподходящих элементов. Оба полных прохода линейны по количеству чисел.

### Разбираем на примере

X = 2; показатели: 0, 1, 2, 5, −3. Ответы: 1, 2, 4, 32, 0.125.

Для отрицательной степени PowerN(2, −3) ждёт 1 / PowerN(2, 3). Та ждёт 2 × PowerN(2, 2). Вторая степень получает половинную степень 2 и возводит её в квадрат, возвращая 4. После этого возвращается 8, затем 1/8 = 0.125.

При X = −2 нечётные степени отрицательные, чётные положительные. Отрицательный показатель означает обратную величину, а не смену знака: (−2)⁻² = 0.25, (−2)⁻³ = −0.125.

Для X = 0 положительные показатели дают 0, нулевой даёт 1 по формуле задания, отрицательные отклоняются в main.

**Ограничение:** отрицательная степень сначала считает положительную. Та может переполниться в бесконечность; обратное станет нулём. Учебная реализация не гарантирует точный ненулевой ответ на крайних значениях.
